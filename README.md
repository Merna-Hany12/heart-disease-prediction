# ❤️ Heart Disease Prediction Web App

This project is a simple **Machine Learning web application** built with **Streamlit**.  
It predicts the likelihood of **heart disease** based on patient medical data such as age, cholesterol, blood pressure, etc.

---

## 🚀 Features
- Enter patient data through an easy-to-use interface  
- Predict whether the patient is likely to have heart disease  
- Show probability of the prediction  
- Visualize dataset trends with charts  

---

## 🛠️ Tech Stack
- **Python**
- **Streamlit**
- **Scikit-learn**
- **Pandas & NumPy**
- **Matplotlib & Seaborn**

---

## ▶️ How to Run
1. Clone the repository  
2. Install dependencies:  
   ```bash
   pip install -r requirements.txt
````

3. Run the app:

   ```bash
   streamlit run app.py
   ```

## 📌 About

This project was created as a learning project to explore **machine learning** and **interactive web apps** using **Streamlit**.
